# Support

Use the following channels depending on what you need:

- Bug reports: [GitHub Issues](https://github.com/SanPen/VeraGrid/issues)
- Feature requests: [GitHub Issues](https://github.com/SanPen/VeraGrid/issues)
- General discussion and quick questions: [Matrix chat](https://matrix.to/#/#veragrid:matrix.org)
- Security reports: private process in [SECURITY.md](SECURITY.md)

Before opening a new issue:

- Search existing issues first
- Include a minimal reproduction when possible
- State the package, version, platform, and input files involved
