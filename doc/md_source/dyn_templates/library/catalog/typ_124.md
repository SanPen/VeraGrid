# sT/(1+sT) (enable)

This is Basic Block Catalog type `124` (`sT/(1+sT) _enable`). It implements logical or event-driven signal behaviour.

<!-- veragrid-block-introduction:start -->
**sT/(1+sT) (enable)** belongs to the hybrid/event layer of a dynamic model. It selects, stores, delays, or switches signals according to conditions, so its result depends on discrete mode or accepted simulation history in addition to the instantaneous continuous variables.

## Typical use

- Use it for protection, enable/disable sequences, sampled control, reset logic, and mode transfer.
- Define initial mode and boundary behavior explicitly to avoid unintended event chattering.
<!-- veragrid-block-introduction:end -->
