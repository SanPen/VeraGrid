# Bistable

This is Basic Block Catalog type `351` (`Bistable`). It implements logical or event-driven signal behaviour.

<!-- veragrid-block-introduction:start -->
**Bistable** evaluates a tabulated characteristic instead of assuming one closed-form equation. Interpolation maps measured or commanded inputs to empirical outputs such as efficiency, saturation, capability, or control schedules while preserving the supplied breakpoints.

## Typical use

- Use it when manufacturer data or a calibrated characteristic is available as points or a matrix.
- Keep breakpoints ordered and decide deliberately whether values outside the table clip or extrapolate.
<!-- veragrid-block-introduction:end -->

## Behaviour

- Library location: `Native / Logic and Events / Gates and Memory`.
- Inputs: 2.
- Outputs: 2.
- Declared states: 0.
- Configurable parameters: 1.
- The imported definition is fully supported by the Dynamic Editor catalogue.

## Characteristic equations

$$
0 = (Bistable_{xSR} - proc_{flipflop\_0})
$$

$$
0 = (Q - (proc_{select\_2} \cdot (proc_{select\_1} \cdot 0 + (1 - proc_{select\_1}) \cdot 1) + (1 - proc_{select\_2}) \cdot Bistable_{xSR}))
$$

$$
0 = (not_{Q} - (1 - Q))
$$
