# Spring

This is Basic Block Catalog type `432` (`Spring`). It represents a mechanical or drive-train relation used by rotating-machine models.

<!-- veragrid-block-introduction:start -->
**Spring** belongs to an electromechanical machine or prime-mover model. It links electrical torque and flux with rotor speed, angle, mechanical power, or actuator dynamics, making it central to frequency, voltage, and rotor-angle stability studies.

## Typical use

- Use it when electrical transients must interact with rotating mass or machine controls.
- Initialize torque, power, flux, and speed consistently with the solved power flow.
<!-- veragrid-block-introduction:end -->

## Behaviour

- Library location: `Native / Mechanical / Drive Train`.
- Inputs: 2.
- Outputs: 1.
- Declared states: 1.
- Configurable parameters: 2.
- The imported definition is fully supported by the Dynamic Editor catalogue.

## Characteristic equations

$$
\frac{d xphi}{dt} = (Spring_{dxphi} \cdot K)
$$

$$
0 = (Spring_{dxphi} - (omega1 - omega2))
$$

$$
0 = (M - (xphi + D \cdot Spring_{dxphi}))
$$
