# Clock (signal)

This is Basic Block Catalog type `480` (`Clock _sig`). It generates or evaluates a time-dependent waveform.

<!-- veragrid-block-introduction:start -->
**Clock (signal)** belongs to the hybrid/event layer of a dynamic model. It selects, stores, delays, or switches signals according to conditions, so its result depends on discrete mode or accepted simulation history in addition to the instantaneous continuous variables.

## Typical use

- Use it for protection, enable/disable sequences, sampled control, reset logic, and mode transfer.
- Define initial mode and boundary behavior explicitly to avoid unintended event chattering.
<!-- veragrid-block-introduction:end -->

## Behaviour

- Library location: `Native / Waveforms and Time / Time Sources and Timers`.
- Inputs: 1.
- Outputs: 1.
- Declared states: 1.
