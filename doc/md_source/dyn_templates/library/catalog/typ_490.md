# Triangle Wave Generator ip

This is Basic Block Catalog type `490` (`Triangle Wave Generator_ip`). It generates or evaluates a time-dependent waveform.

<!-- veragrid-block-introduction:start -->
**Triangle Wave Generator ip** belongs to an electromechanical machine or prime-mover model. It links electrical torque and flux with rotor speed, angle, mechanical power, or actuator dynamics, making it central to frequency, voltage, and rotor-angle stability studies.

## Typical use

- Use it when electrical transients must interact with rotating mass or machine controls.
- Initialize torque, power, flux, and speed consistently with the solved power flow.
<!-- veragrid-block-introduction:end -->
