# dq0->abc (power variant -- align a->d)

This is Basic Block Catalog type `550` (`dq0->abc (power variant -- align a->d)`). It converts signals between the coordinate systems or units identified by the block name.

**dq0->abc (power variant -- align a->d)** is a coordinate-transformation block. In three-phase analysis, Clarke and Park transforms separate stationary or rotating components so sinusoidal phase quantities can be controlled as nearly constant d-q signals. The selected scaling determines whether amplitude or instantaneous power is preserved.

## Typical use

- Use it to connect phase-domain electrical quantities with d-q or sequence-domain control laws.
- Keep angle orientation, axis alignment, phase order, and power/amplitude convention consistent.
