== Introduction

This ReadMe complements the machine-readable link:manifest.xml[manifest] and provides a human-readable description of the content and structure of this package.

This package represents a power system model compliant with the *Common Grid Model Exchange Standard (CGMES)*, as defined by ENTSO-E and based on the IEC CIM standards.

The model is intended for use in interoperability scenarios, including:

* power system analysis (e.g. load flow, contingency analysis)
* data exchange between TSOs, RCCs, and market participants
* validation and conformance testing
* tooling and research using standardized datasets

The package is provided in multiple serializations:

* `cimxml/` – Contains CIM XML files (RDF/XML) according to *IEC 61970-600-1*, with alignment to *IEC 61970-552:2016*.  
  This is the primary format used by CGMES-compliant power system tools.

* `jsonld/` – Contains CIM JSON-LD representations aligned with *IEC 61970-553* (under development).  
  This format enables integration with *Semantic Web technologies* and modern data ecosystems.

* `trig/` – Contains link:https://www.w3.org/TR/trig/[TriG] representations of the model.  
  This format is intended for improved human readability and semantic inspection.

== Authoritative Representation

The authoritative representation of the model is currently maintained in the `cimxml/` folder.

All other serializations are derived from this source:

* JSON-LD is generated from CIM XML and located in `jsonld/`
* TriG is generated from CIM XML and located in `trig/`

[quote]
____
CIM XML SHALL be treated as the authoritative exchange format for this package unless otherwise explicitly stated.
____

== Validation Approach

The model is validated against:

* *CGMES 3.0* profile definitions
* SHACL constraints representing profile rules and semantic validation

Validation activities may include:

* syntax validation of RDF/XML and JSON-LD
* profile conformance validation using SHACL
* semantic consistency checks across datasets
* functional validation using CGMES-compliant power system analysis tools

The CIM XML representation is expected to be compatible with power flow tools supporting CGMES.

== Changelog

This package follows *Semantic Versioning 2.0.0* (link:https://semver.org/[SemVer]) with support for **pre-release versions**:

`{Major}.{Minor}.{Patch}-{PreRelease}.{Iteration}`

* **Major (`X.0.0`)** – Non-backwards-compatible changes  
  (e.g. transition to a new CGMES version or structural redesign)

* **Minor (`X.Y.0`)** – Backwards-compatible enhancements  
  (e.g. addition of new objects or datasets compliant with the same profile)

* **Patch (`X.Y.Z`)** – Corrections or minor adjustments  
  (e.g. attribute updates or corrections without structural impact)

* **Pre-release (`alpha`, `beta`)** – Versions under development

* **Iteration (`X`)** – Sequential build number within the pre-release phase
